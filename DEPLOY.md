# Запуск ПРОЕКТСЕТЬ

## Render
Репозиторий содержит `render.yaml`, поэтому настройки запуска уже заданы.

1. В Render создать Blueprint из репозитория `proektset/bot`.
2. При запросе переменной `TELEGRAM_BOT_TOKEN` вставить токен из BotFather.
3. Запустить deploy.
4. Открыть @proektset_bot и нажать Start.

Секретный токен нельзя сохранять в GitHub.

## Telegram
После запуска:
- /start — меню
- /help — справка
- /kep — переход к расчёту КЭП

Бота можно добавить в группу ПРОЕКТСЕТЬ. Для базового меню права администратора не требуются.
