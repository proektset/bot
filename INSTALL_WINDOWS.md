# ПРОЕКТСЕТЬ — запуск на Windows

## Самый простой запуск

1. Скачайте репозиторий как ZIP: GitHub → Code → Download ZIP.
2. Распакуйте ZIP в постоянную папку, например `C:\PROEKTSET_BOT`.
3. Дважды нажмите `START_PROEKTSET_BOT.bat`.
4. При первом запуске вставьте токен BotFather и нажмите Enter.
5. Откройте @proektset_bot в Telegram и нажмите Start.

Скрипт сам:
- создаёт локальное Python-окружение;
- устанавливает зависимости;
- создаёт локальный .env;
- запускает бота.

Файл .env исключён из Git и не должен попадать в репозиторий.

## Важно

Пока окно START_PROEKTSET_BOT.bat открыто и компьютер работает, бот работает. Если компьютер выключить или закрыть окно, бот остановится.

## Повторный запуск

Просто снова запустите `START_PROEKTSET_BOT.bat`. Токен повторно вводить не требуется.

## Смена токена

Удалите локальный файл `.env` и снова запустите START_PROEKTSET_BOT.bat.
