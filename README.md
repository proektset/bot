# ПРОЕКТСЕТЬ — Telegram bot

Стартовая версия бота профессионального сообщества «ПРОЕКТСЕТЬ».

## Меню
- Правила группы
- Эффективность
- Проектирование

## Запуск
1. Python 3.11+
2. `pip install -r requirements.txt`
3. Создать `.env` по примеру `.env.example`
4. Добавить токен BotFather в `TELEGRAM_BOT_TOKEN`
5. `python bot.py`

Токен бота не хранить в GitHub.
